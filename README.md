# Little Wisdom ✦

Life tips, life-lesson quotes and motivation as picture cards you can share with friends.

## Features

- **9 topics:** Life lessons, Motivation, Mindset, Happiness, Health, Money, Friends & love, Work & goals, Confidence
- **Animated graphics** that match each topic (sun, flame, book, coin, heart, rocket, crown, light bulb)
- **6 card styles:** Sunrise, Ocean, Midnight, Forest, Paper, Lilac
- **Swipe** left for the next card, right to go back (arrow keys work on desktop)
- **Your name** on every card (defaults to "Shanez")
- **Save picture** (PNG) or **Save video** (5-second animated MP4/WebM), which opens the phone's share sheet
- **Copy text** to paste anywhere

## Run it

It's a single file with no build step. Open `index.html` in a browser, or host the folder on GitHub Pages.

The "Make a card for your situation" section uses Claude, so it only appears when the app runs inside Claude.
